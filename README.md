# CampusNotes - CSE25303

CampusNotes is a simple repository for organizing and maintaining computer science study notes.

## Features
- Store subject-wise study notes
- Organize academic topics
- Easy access to learning material
- Support for future note additions

## Subjects
- Introduction to Git
- Version Control Systems
- Data Structures and Algorithms
- Java Programming

## Getting Started
1. Clone the repository.
2. Open the project folder.
3. Read the notes available in notes.txt.
4. Add new notes as required.

## Project Structure
- README.md - Project information and instructions
- notes.txt - Study notes
